# QA Automation Lab
Репозиторий с автотестами для лабораторных работ по тестированию ПО.

## Содержание
- `calculator.py` — класс Calculator (сложение, вычитание, умножение, деление, проверка простого числа)
- `test_calculator.py` — базовые модульные тесты
- `test_calculator2.py` — параметризованные тесты и проверки исключений

## Запуск локально
pip install -r requirements.txt
pytest -v
